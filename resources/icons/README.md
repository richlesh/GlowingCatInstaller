# Project Icons

Place one PNG per project here. The app loads icons by the filenames listed below
(see `src/model.rs`, field `icon`). Recommended size: 128x128 or 256x256, square.

If an icon file is missing, the app falls back to a built-in placeholder, so the
UI still works before you add images.
